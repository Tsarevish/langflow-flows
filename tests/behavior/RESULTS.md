# Независимая оценка агента — 14.11.2026

Три агента с чистым контекстом получили скилл, задачи словами и минимальные исходные
данные. Они не читали tests/, готовые spec-файлы или выводы разработчика. Оценка
проводилась по графам, diff, trace, ответам API, session IDs и контрольным GET после удаления.

Итог: **8 сценариев подтверждены полностью, 2 — частично**. Это проверка поведения
при применении скилла, отдельная от интеграционного прогона готовых spec.

## Ограничения методики

- B02 и B04 используют один артефакт чата; это не две независимые попытки модели.
- В необходимом справочнике формата есть минимальный пример эхо, хотя отдельные
  готовые spec-файлы оценщикам не давались.
- B07 не подтверждает live-обработку буквального False без флага: сервер вернул isError=true.
- B08 отрицательная проверка завершилась раньше получения схем, на доступе к стенду.
  Изолированный отказ схем покрыт модульным тестом, а не этим live-опытом.
- Контрольная группа без скилла и повторы с разными случайными параметрами не выполнялись.
- Оценивались рабочие инструкции 0.4.0. Узкие исправления по найденным затруднениям
  включены в 0.4.1; полный повтор независимой оценки после них не проводился.

## Артефакты

В рабочем проекте исходные ответы, скрипты, diff и доказательства очистки находятся в:

- `output/independent-echo-edit/`;
- `output/independent-tools-memory/`;
- `output/independent-offline/`;
- `output/independent-diagnostics-profile/`;
- `output/independent-transfer/`.

Сводка с указанием доказательств каждого случая — `output/independent-evaluation/results.json`.
В поставляемый скилл входят только задачи, методика и этот отчёт; сырые live-артефакты
и реальные профили в пакет не включаются.

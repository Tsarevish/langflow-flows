# dsh-langflow-flows-skill

Плагин-бандл DSH, который устанавливает скилл `langflow-flows` и показывает его
в разделе «Плагины».

## Что делает

Добавляет отдельный провайдер скиллов с изолированными корнями и указывает ему
на `skills/` внутри пакета. Скилл становится виден агенту как `langflow-flows`,
без ручного копирования файлов.

## Установка

```
plugin_manager: install_bundle, target = github:Tsarevish/langflow-flows#path:/bundle
```

Или локально, из склонированного репозитория:

```
plugin_manager: install_bundle, target = file:<путь>/langflow-flows/bundle
```

После установки проверь: в списке скиллов появился `langflow-flows`.
Если он уже стоял вручную в `~/.dsh/skills`, убери оттуда копию — иначе будет дубль.

## Что внутри

```
cordis.patch.yml   вставка провайдера скиллов
skills/langflow-flows/   сам скилл: SKILL.md, справочники, примеры, скрипты
```

## Границы

Бандл ставит **только скилл**. MCP-сервер Langflow подключается отдельно:
у каждого свой адрес и ключ, их нельзя зашить в пакет. Строка для
`cordis.patch.yml` профиля — в README репозитория.

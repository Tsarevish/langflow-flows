# Ручные настройки стенда

Создать профиль: `python scripts/probe_stand.py --url <URL>`.
Ключ — в LANGFLOW_API_KEY или защищённом локальном env-файле.
Измеренные URL/версия/возможности — в profile.auto.md и components.json.
Эта карточка сохраняется при обновлении; старые измеренные сведения проверяй по auto.

## Модель

Провайдер, API base, имя модели, имя credential-переменной (не её значение).
Дата и результат проверки запуска.

## Ограничения

Время запуска, параллельность, доступ к файлам и интернету, поддерживаемые форматы.
Отмечай источник и дату проверки каждого ограничения.

## Особенности

Расширения, динамические схемы, права и рабочие обходные пути.

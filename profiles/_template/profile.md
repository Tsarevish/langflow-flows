# Профиль стенда

Профиль создаётся скриптом:

```
python scripts/probe_stand.py --url http://localhost:7860 --key sk-...
```

и попадает в `profiles/stand-<host>/profile.md`. Этот файл — шаблон: разделы
«Ограничения» и «Особенности» скрипт заполнить не может, их дописывают вручную.
Рецепты проверок — `references/recon.md`.
